# North & Loom

A portfolio-grade MERN storefront for considered homeware. It includes product discovery, category filtering, search, wishlists, product details, a persistent-session cart, and a card-free test checkout.

## Run locally

```bash
npm install
npm run dev
```

The storefront runs on `http://localhost:5173` and the API on `http://localhost:5100`.

Copy `server/.env.example` to `server/.env` and add a MongoDB Atlas connection string before using database-backed product and order routes.
